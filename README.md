## Overview
This repository contains the Python implementations of fundamental linear data structures: **Stack** and **Queue**, built using both fixed-size arrays and dynamic linked lists.

## Project Structure
- `structures.py`: Contains class definitions for `ArrayStack`, `LinkedStack`, `ArrayQueue`, and `LinkedQueue`.
- `main.py`: Interactive menu-driven program for testing individual operations on each data structure.
- `applications.py`: Practical applications including balanced parentheses checking and print job queuing.
- `analysis.md`: Detailed written analysis of linked list stack operations and circular array queue mechanics.

## How to Run

### Interactive Menu Program
```bash
python main.py
```

### Application Exercises
```bash
python applications.py
```
